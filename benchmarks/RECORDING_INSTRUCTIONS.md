# Recording Instructions — Send This to Your Friends

We need **20 short voice notes** for a speech-to-text benchmark. Each one is
you reading ONE line below, like you're a customer in Lagos asking an artisan
to come do a job for you. Total time: about 10 minutes.

## How to Record

1. Use your phone's normal **voice recorder** app (WhatsApp voice notes also fine).
2. Find a **quiet-ish** spot — indoors is better than the street, but it doesn't need to be a studio.
3. Hold the phone like you're on a call, **15–30 cm from your mouth**.
4. Read the line **naturally, like you're actually saying it to somebody** — normal speed, normal Pidgin. Don't read like a robot, don't shout, don't whisper.
5. Say the line once, then **stop the recording**. Each clip should be about 5–10 seconds.
6. **One line = one recording.** Don't record two lines in one file.

## ⚠️ File Naming — VERY Important

Name each file exactly like this, using the number of the line you read:

| Line | File name |
|---|---|
| 1 | `note01` |
| 2 | `note02` |
| 3 | `note03` |
| ... | ... |
| 20 | `note20` |

- **The zero in front matters** (`note01`, NOT `note1`) — the computer sorts the files by name, and `note1, note10, note11` sorts before `note2`, which would scramble everything.
- The app will add the extension automatically (`.m4a`, `.aac`, `.opus`, whatever your phone uses — all fine).
